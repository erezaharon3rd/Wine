# שינויים במסד

כל שינוי במבנה המסד נכתב כקובץ חדש בתיקייה הזו, עם תאריך בתחילת השם:
`YYYYMMDDHHMMSS_מה_השתנה.sql`. לא עורכים קובץ שכבר הורץ.

- `20261119000000_baseline.sql` הוא מצב המסד היום, זהה ל־`supabase/setup.sql`.
- קובץ חדש מריצים קודם בפרויקט הניסיון (staging), ורק אחרי שהבדיקות עוברות בפרויקט האמיתי.
- `setup.sql` נשאר תמיד המצב המלא והעדכני, ובטוח להרצה חוזרת. כל שינוי נכנס גם אליו.
